# NovaHelm

Open-source tools for people who build and stream from their own machines. This repository is where they are built in
the open; more of them move here over time.

| Folder                   | What it is                                                                                     | Licence    |
| ------------------------ | ---------------------------------------------------------------------------------------------- | ---------- |
| [`novagear/`](novagear/) | One small app for Elgato Key Lights, Stream Deck +, the Prompter, capture cards and Razer mice | Apache-2.0 |
| [`novaui/`](novaui/)     | Shared SwiftUI building blocks for the Nova menu bar apps                                      | Apache-2.0 |
| [`brand/`](brand/)       | The Nova app icons, used by the app builds (trademark rules below)                             | Apache-2.0 |

## Our licence promise

Every folder has its own `LICENSE`, and the `LICENSE` at the root (Apache-2.0) covers anything a folder's own file
doesn't. Apps that run on your machine and the shared kits are Apache-2.0; the NovaHelm cloud,
when it lands here, will be AGPL-3.0. These licences won't change: no move to a "source available" licence, no
features held back under a separate licence, and no CLA. Contributions use a DCO sign-off instead (see
[CONTRIBUTING.md](CONTRIBUTING.md)).

The code is open, but the Nova names and logos (including the icons in `brand/`) are trademarks. You may use them to
refer to the projects, not to brand your own fork; see [TRADEMARKS.md](TRADEMARKS.md).
